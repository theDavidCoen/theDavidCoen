### What I Do

- **QA** — manual testing on real Android & iOS devices; multi-chain wallet flows, swaps, buy/sell, sync issues; clear repro steps in Asana
- **Device lab** — [QA Dashboard](https://github.com/theDavidCoen/QADashboard) for multi-device control (scrcpy / libimobiledevice), screenshots, recordings, and common QA actions
- **Support** — Intercom inbox, Help Center, Fin/Prudence guidance, voucher & login lookup tooling
- **Team workflow** — Slack, Asana boards, GitHub issues, Sentry for crash triage, Cursor for day-to-day work
- **Bitcoin products** — consulting with Ark Labs (Arkade and related products)
- **Self-hosted infra** — BTCPay, Lightning node, Nostr relay, status & resource tools on [davidcoen.it](https://davidcoen.it/)
- **Open resources** — [LightningExchanges](https://github.com/theDavidCoen/LightningExchanges), [Q/A about Bitcoin](https://github.com/theDavidCoen/Q-A-about-Bitcoin), and more
